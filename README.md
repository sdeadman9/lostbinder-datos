# lostbinder-datos

Datos estáticos para **Gengar's Lost Binder**, servidos gratis con GitHub Pages:

- `catalogo/`: todas las cartas Pokémon TCG en inglés. Se reconstruye cada lunes desde [tcgcsv.com](https://tcgcsv.com) (datos de TCGplayer) con `scripts/construir_catalogo.py`.
- `vendor/tesseract/`: lector de texto del escáner (Tesseract.js 5.1.1, Apache-2.0, sin modificaciones).

Para actualizar a mano: pestaña **Actions** → «Publicar catálogo» → **Run workflow**.

Proyecto de fans sin afiliación con Nintendo, Creatures, GAME FREAK, The Pokémon Company ni TCGplayer.
